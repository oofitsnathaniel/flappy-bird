## 🎮 Play the Game

### **[▶ Play Flappy Bird in Your Browser](https://oofitsnathaniel.github.io/flappy-bird/)**

No downloads, installations, or accounts required.

Play directly in your browser on desktop, iPhone, or Android.

**The goal is simple:** Tap or press Space to flap your wings, navigate between pipes, and beat your highest score.

One wrong move, and it's game over!

---

## ✨ Features

### 🕹️ Classic Gameplay
- Familiar Flappy Bird mechanics and visuals.
- Responsive keyboard, mouse, and touchscreen controls.
- Improved collision detection with rotation-aware bird hitboxes.
- Consistent gameplay physics across different refresh rates.
- Locally saved high scores.

### 👻 Ghost Challenge
Compete against your previous best performance!

- Record your best challenge run automatically.
- Race against a translucent replay of your previous attempt.
- Adjustable ghost visibility.
- Consistent pipe layouts for comparable runs.
- Separate records for Classic Mode and Ghost Challenge.

Your ghost is visual only and never interferes with gameplay.

### 🎨 Skins & Customization

Personalize your game with several visual options.

**Bird Skins**
- 🟡 Yellow
- 🔴 Red
- 🔵 Blue
- 🎲 Random

**Pipe Skins**
- 🟢 Green
- 🔴 Red
- 🎲 Random

**Sky Backgrounds**
- ☀️ Day
- 🌙 Night
- 🌅 Sunset
- 🌆 Dusk
- ☁️ Overcast
- 🎲 Random

Customization preferences are saved locally.

### 🏆 Statistics & Achievements
Track your progress through an integrated statistics and achievement system.

- Games played
- Total pipes passed
- Personal best
- Time played
- Unlockable achievements

### ⚡ Performance & Optimization
Designed to remain lightweight while delivering smooth gameplay.

- HTML5 Canvas rendering.
- Fixed-timestep physics with interpolated visuals.
- Adjustable rendering limits.
- Support for high-refresh-rate displays.
- Optimized Canvas scaling.
- Web Audio API for responsive sound effects.
- Low-power rendering option.
- Optional performance diagnostics.

### 📱 Mobile Support
Optimized for mobile browsers, including iPhone Safari.

- Touch-to-flap controls.
- Automatic mobile detection.
- Portrait display support.
- Mobile-friendly settings.
- Touch and viewport stability improvements.
- Responsive rendering across different screen sizes.

## 🎮 Controls

| Action | Desktop | Mobile |
|---|---|---|
| Flap | Space / Up Arrow / Click | Tap |
| Pause | P | Menu |
| Menu | Esc | Menu button |
| Fullscreen | F | Browser-dependent |
| Change display | M | Settings |
| Performance overlay | F3 | — |

Controller support is also included for compatible browser gamepads.

## ⚙️ Display Options

Choose the display mode that works best for your screen.

| Mode | Description |
|---|---|
| Original Portrait | Traditional Flappy Bird aspect ratio |
| Expanded Fullscreen | Expands the visible playfield to fit your screen |
| Ultrawide 21:9 | Designed for wider monitors |

The game preserves its classic gameplay physics regardless of display mode.

## 🛠️ Built With

- **HTML5** — Game structure and interface
- **CSS3** — Menus, responsive layout, and styling
- **JavaScript** — Game logic, physics, and customization
- **Canvas API** — Graphics and animation
- **Web Audio API** — Sound playback
- **Local Storage** — High scores, preferences, achievements, and ghost data

The game runs entirely in your browser, with no account or backend server required.

---

## 🔒 Privacy

Flappy Bird is designed as a client-side game.

- No account required.
- No gameplay telemetry added.
- No external game database.
- Scores and settings are stored in your browser.
- Ghost recordings remain on your device.

Standard hosting and browser behavior still apply.

## 🚀 Running Locally

1. Download the game's `index.html`.
2. Open it in a compatible desktop browser.
3. Start playing!

For the most reliable experience on iPhone, play through the hosted website in Safari.
